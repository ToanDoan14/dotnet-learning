# Day 01 - Console Input & Variables

## ⏱️ Study Time
1 giờ 30 phút

## 📚 Nội dung học

- Console.WriteLine()
- Console.ReadLine()
- Variable
- string
- int
- float
- Parse()

## 😕 Khó nhất

Hiểu Parse() hoạt động như thế nào.
Ban đầu mình nghĩ Parse giúp ReadLine hiểu dữ liệu, sau đó mới hiểu rằng Parse dùng để chuyển string sang kiểu dữ liệu khác.

## 😊 Hiểu nhất

Console.ReadLine() luôn trả về string.

## 💡 Điều học được

- Console.ReadLine() luôn trả về string.
- int.Parse() tạo ra một giá trị int mới.
- Parse() không thay đổi biến gốc.

## 🐛 Lỗi mình gặp

- int age = Console.ReadLine();
- int.Parse(age);
- float.Parse(height);

## ✅ Cách sửa

Sử dụng:

int.Parse(Console.ReadLine());
