# DAY02

## Variable là gì ?
- Variable là vùng có tên dùng để lưu dữ liệu
Ví dụ: int age = 25;
       age là tên biến
       21 là kiểu dữ liệu được lưu.
       int là kiểu dữ liệu của biến.

## DataType là gì ?
- DataType là kiểu dữ liệu, cho chương trình biết dữ liệu đó được lưu và xử lý thế nào.
- Ví dụ: int - số nguyên, double - số thực, string - chuỗi ký tự, bool - đúng, sai 

## Char và string tại sao khác nhau ?
- String là một chuỗi các ký tự trong khi đó char là một ký tự đơn lẻ, giả sử khi lấy một ký tự từ chuỗi string sẽ là char
Ví dụ: Char 'T', String "Toàn"

## Hiểu thêm điều gì về Parse() ?
- Parse là một dạng để chuyển chuỗi (string) sang kiểu dữ liệu mong muốn
- Ví dụ: string text = "25"; int age = int.Prase(text); Nếu chuỗi string text = "abc"; không hợp lệ thì int.Prase(text) sẽ báo lỗi.
